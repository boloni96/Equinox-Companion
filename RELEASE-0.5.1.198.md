# Companion 0.5.1.198

Adventure event and reward rows now show their names without repetitive action suffixes. Complete event activity and Collect reward appear in the hover information alongside the current confirmation status.

This is a presentation change; shared task IDs, automatic confirmation, pairing and server sync are unchanged. Existing saved adventures benefit immediately, without rebuilding them or redeploying the Journal.

User validation before this release: event quest, bear clothing and furnishing confirmation, paired plugin progress and reopening the Journal all passed with both Journals closed during gameplay.
