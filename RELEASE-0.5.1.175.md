# Companion 0.5.1.175

/bid → Upgrade matches now offers three check scopes:

- All paired characters: configured upgrades and favourite plots across paired home worlds.
- Selected upgrade watches: choose active property watches, with select-all and clear controls.
- This character’s upgrades: only the logged-in paired character’s watches and favourite matches.

Manual checks report checked worlds and partial failures. Scope and character changes clear stale manual results. Background checks retain their configured-watch behavior and no longer reset pagination while manual results are shown.

All/current-character checks require Journal V7.11.183. No additional Journal changes. In-game validation remains necessary.
