# Companion 0.5.1.174

/bid now has four separate views: Find plots, Saved plots, Favourite plots, and Upgrade matches. Favourite and saved lists have their own scrollable area instead of stacking above the search results. Find plots keeps the current filters and paired bids.

Saved plots explain that they are exact houses stored on this computer. Favourite plots explain that they are shared location preferences for upgrade watches, including equivalent plots and optional ward restrictions. Favourite sync status appears once in its view; saves and failures remain briefly visible from the plot finder. Opening the Favourite plots view requests a fresh shared list.

Uses the existing Journal V7.11.182 API. No Journal deployment is needed for this layout change. Sync behavior and existing saved records are preserved. In-game visual validation remains necessary.
