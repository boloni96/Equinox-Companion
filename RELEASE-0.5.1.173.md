# Companion 0.5.1.173

Favourite plot stars in /bid now open a native save choice: any ward or the selected ward. Matching both equivalent main/subdivision plots defaults on. No browser is opened for this action.

A Favourite plots section in /bid lists the shared district, plot pair and ward restrictions, with Refresh, Copy and Remove. Writes use the paired endpoint immediately, and shared favourites refresh independently of the Journal browser. Saved plots remain a separate exact-estate shortlist. Upgrade watch configuration still opens the Journal.

Deploy Journal V7.11.182 for the new authenticated favourite API. Requests are bounded, revision checked, and failed writes display an error without claiming a save. In-game UI validation is still required.
