# Companion 0.5.1.583

Workshop material reviews now offer All materials, Turn-ins only and Ingredients only (including intermediate crafts). These filter the rows, keeping shared queue totals and stock allocation unchanged; items used in both roles appear in both views. Hover shows direct versus ingredient demand. Shopping and withdrawal actions continue to use the whole reviewed queue.

Blue means every remaining craft is covered by recorded ingredients. A craftable turn-in can be red even when its own raw shortage is zero because a downstream ingredient is missing. Those rows now show Inputs in the Missing column, and hover identifies the missing ingredients. The shared Info colour legend explains the distinction. The same missing-input explanation applies in Crafting. No colour meanings or availability requirements have been relaxed.

Tests cover full ingredient coverage, missing shards propagating through subcrafts, covered stock staying gold, owned turn-ins not acquiring irrelevant crafting blockers, and turn-in/ingredient view overlap without double counting. Retains all 0.5.1.582 shopping, clipboard, material-total and inventory-refresh changes. In-game UI verification remains pending.

Fix a material overcount: when a turn-in is also a crafting ingredient, preserve its surplus bag/retainer/FC stock for that ingredient demand. Previously the review replaced its entire stock count with only the direct turn-in allocation, which could create unnecessary subcrafts and crystal shortages. Direct delivery keeps its NQ/HQ whole-set allocation; incompatible leftover quality is usable only for ingredient demand. Regression cases cover bag surplus, stored surplus and mixed-quality sets.

Workshop Artisan export: unchecked missing-only mode now builds a complete stock-free recipe graph from the remaining turn-ins, rather than increasing quantities only for recipes left in the reduced plan. Fully owned outputs and their subcrafts can therefore be included. Copy refreshes material stock, reports the number of recipes/crafts, and offers an expandable exact copied-recipe list. Regression tests reproduce 26 full versus 23 stock-adjusted recipes, fully owned queues, recipe yields, and covered intermediate recipes. The clipboard sets SkipLiteral so full targets include direct output plus ingredient demand.

Artisan import currently calls Save(true), which overwrites SkipIfEnough with the user's Artisan default. Companion now tells the user to verify the imported setting: OFF for exact missing quantities, ON for full requirements. Automatic subcraft adjustment can also change quantities after editing. No Artisan configuration file is modified.
