# 0.5.1.294

- Plans can save whole category rules for both Withdraw and Entrust, including Crystals.
- Rule amounts set withdrawal per item type and the amount to keep when entrusting. Explicit item settings and imported protection take priority.
- Category-only plans are supported; no need to list every matching item. Category items without available stock are skipped.
- Existing imported category Keep values remain intact until edited.
