quest-routes.zip contains all 4,392 original QuestPaths JSON files, including 4,388
route definitions. Original author fields and JSON bytes are retained. The pack
includes the upstream AGPL-3.0 LICENSE, NOTICE and source mapping files used to
resolve symbolic aetheryte and emote identifiers. Complete corresponding upstream
source is pinned as vendor/questionable-data-source in this repository.

Companion's reader, planner and step runner are independently implemented.
The runner does not load or call the Questionable plugin. Data import is not a
claim that every interaction is automated: unsupported steps and conditions are
reported and left pending. Duties and solo duties remain manual.

Local navigation samples FFXIV's live BGCollisionModule through the public
FFXIVClientStructs API. A bounded incremental search connects ground positions
only after checking support, step height and body clearance. The movement
controller uses the game's UI-filtered movement input and releases its input on
stop, dialogue, user movement, zoning or deadline. No vnavmesh code is copied,
and neither vnavmesh nor Questionable is required. Live route validation is still
necessary; this is local ground navigation, not a full-zone or flying mesh.

Lifestream remains the existing integration for aethernet/world/account travel.
Keyward Bound's dedicated quest runner and reward/account workflow use Companion
local navigation. The current game's quest text sheets supply localized prompts.
Manual recorder exports remain observations for review, not automatic replay.
