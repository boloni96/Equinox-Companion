# Equinox Companion 0.5.1.81 — one FollowThem top-bar entry

Being followed now uses the existing FollowThem entry: `FollowThem: Followed by Character Name`. The separate Helper Leader entry has been removed. Left-click pauses/resumes the active followers; right-click opens Helper Controls. If also following someone, the same entry shows the followed role and Helper Controls retains the local Stop button. After the last active follower leaves, the entry returns to its ordinary follower/STOPPED state.

Journal V7.11.82 remains current; no new website deployment package is needed. Quick test: start a follower, verify one entry and exact name, pause/resume with left-click, open controls with right-click, stop follower and verify ordinary text returns. Check both roles together if used.
