# Equinox Companion 0.5.1.239

Optional Goddess-blue design with tighter spacing across Equinox windows. The welcome screen previews the design and offers **Use the new design** or **Keep the current design**; Settings → Appearance can change it later. The local choice survives updates and does not alter pairing or gameplay settings.

The new Companion menu keeps each Person, My Empire, Gardening, Submarines and optional tools, adds a Testing section, and pins Settings below its scrollable menu. At narrow widths it uses icons with hover names. Content scrolls separately. Existing house, Fashion Report, Journal and minimised icons remain available. The current tab layout is retained as an option.

Adventure now shows **done / total activities** across the saved adventure, separately from the current stop. Shared tasks count once. The window can shrink to 360 × 280; portraits adapt, the world selector stays bounded, and Bring here / Cancel bring wrap when needed. Navigation does not mark work complete.

Gardening and Fashion Report keybinds now toggle their windows open and closed, as the Equinox keybind does. Commands retain their existing open behaviour. Travel/login checks and garden detection, bed mapping, plan order and confirmation rules are unchanged.

Validation: transition/regression suite, dedicated preference migration/persistence and narrow-layout checks, native garden text suite, and Release build. In-game appearance, resizing and keybind validation still required. This release does not require a Journal or scheduled Worker deployment.
