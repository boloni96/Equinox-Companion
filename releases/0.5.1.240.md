# Equinox Companion 0.5.1.240

Settings and other submenu tabs now use the Goddess-blue palette and compact rounded corners when the new design is selected. Selected, hovered and unfocused tabs stay consistent with the surrounding window. Their familiar horizontal navigation remains available.

The original design option is unchanged. Styling remains scoped to Equinox windows. Garden detection, bed mapping, sync and travel behaviour are unchanged. No Journal or scheduled Worker deployment is required.

Validation: the existing transition/regression suite, native garden text suite and Release build must pass before publication. In-game visual confirmation is still required.
