# Companion 0.5.1.193

- Game & plugin actions opens the real game item-reference menu beside the originating Companion window, allowing installed plugins to add their own supported entries and submenus.
- Companion remains visible. If no side has room, move or resize it and retry. Other overlapping plugin windows and unusually wide native submenus may still need repositioning.
- This is an item-reference menu, not a forged inventory slot. Inventory-only actions such as Discard, Meld and slot moves remain in the real inventory.
- Plugins decide whether to offer their actions for this item-reference context; this does not promise every inventory-only plugin entry.
- Craft one remains removed. Search crafting recipes and Open crafting lists remain available.
- No Journal deployment required. Native menu positioning and third-party entries require in-game verification.
