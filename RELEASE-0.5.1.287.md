# Companion 0.5.1.287

Withdrawal now starts with this character's retainers recorded as holding the
missing requested items, using Companion/Allagan stock already loaded by the
preview. Bag subtraction and NQ/HQ settings affect the choice. No preliminary
tour of all retainers is needed.

Live inventory still confirms each withdrawal. Once bag quantities are satisfied,
the run ends without opening the other retainers. If recorded stock is insufficient
or stale, remaining retainers become a fallback, labelled Checking missing stock.
Other characters' retainers are never included. Already-held requests finish
without opening a retainer.

Includes .285 crafting ingredient/raw-material menu actions and nearby bell
opening, plus .286 dedicated crystal Entrust/Withdraw and FC chest Entrust plans.

Test with an item recorded only on a later retainer: it should open that holder
first, withdraw and finish. Also test an outdated record: it should check remaining
retainers only while items are still missing. In-game verification is required.
