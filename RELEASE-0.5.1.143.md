# Companion 0.5.1.143

Click the star beside a plot's district in /bid to save or remove a favorite. Favorites only filters the current world's reports alongside the existing filters. Clear sort and filters clears this view filter without deleting saved favorites.

Saved favorites is an expandable cross-world shortlist with Search world, GO SEE and Copy actions. It retains addresses even if Paissa no longer lists the plot or filters hide it. A bookmark makes no claim about current availability or whether a bid was submitted.

Favorites persist in local Companion configuration across plugin updates, game restarts and character switches on this installation. Saving happens only when a star is toggled. Favorites are not sent to Journal or paired computers. No Journal update required.

Validated with a Release build and the regression suite, including favorite address identity, JSON round trip and configuration snapshot isolation. In-game visual verification remains necessary.
