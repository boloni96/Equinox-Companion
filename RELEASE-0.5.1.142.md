# Companion 0.5.1.142

Click a /bid sortable heading once for ascending order, twice for descending, and a third time to restore default order. Switching to another column starts ascending.

Default order is Mist, Lavender Beds, Goblet, Shirogane, Empyreum, then numeric ward and plot. It applies initially, after the third click, and when clearing sort and filters. Equal sorted values also use this address order. Restoring default via the heading preserves filters.

Validated with the Release build and regression suite, including the three-click cycle and numeric ward/plot ordering. No Journal update required.
